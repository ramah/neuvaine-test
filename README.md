# neuvaine-test

Dépôt **temporaire** : page de test d'une neuvaine reçue, découpée en jours (introduction, prière du jour, prières répétées), avec rappel simulé et lecture à voix haute par la voix du téléphone. Début d'un projet web Astro.

- Les textes sont ceux reçus, sans modification, et ne sont pas de nous. Page non référencée (`noindex`, `robots.txt`), à supprimer après les essais.
- Données : `src/data/neuvaine.json`. Page : `src/pages/index.astro`.

```sh
npm install && npm run dev
```
